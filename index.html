COMMON QUESTIONS

Before you enrol.

Clear answers. No vague promises.

How are lessons delivered?+

Lessons are delivered live online using the learner's phone, tablet or computer. The final class links and communication channels are provided after registration.

How many lessons does each subject receive?+

The target structure is four sessions per subject each week, supported by assignments, revision and feedback.

Can parents track progress?+

Yes. The parent experience is designed to show attendance, results, notices, fees and teacher communication without exposing unnecessary student or admin controls.

Does registration guarantee placement?+

No. Placement depends on the selected subject, academic level and available timetable slots. The academy confirms the final class after reviewing the registration.

Is the platform already fully operational?+

This website includes working interactive portal prototypes. Live classes, payments, authentication and permanent cloud data require the next backend integration stage.
